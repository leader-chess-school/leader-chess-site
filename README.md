# Сайт шахматной школы «Лидер»

Исходный код публичного сайта [chess-spb.com](https://chess-spb.com).

Vite + React + TypeScript, сборка с пререндером: каждая страница отдаётся готовым
HTML. Три страницы — главная, цены, расписание.

Тексты сайта лежат в `src/content/` — расписание, цены, блоки главной, меню.
Правки туда; вёрстку и компоненты трогать для этого не нужно.

```sh
npm install
npm run dev     # локальный просмотр
npm run build   # полная сборка, как на проде
```

Деплой автоматический: пуш в `main` — и сайт обновляется. Ветка даёт ссылку на
предпросмотр, живой сайт при этом не меняется.

Как всё устроено подробнее — `CLAUDE.md` в корне.
