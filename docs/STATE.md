# chess-leader/website — STATE

Snapshot of the system. Updated by hand after notable changes.

## Live

Primary: [chess-spb.com](https://chess-spb.com) — DNS cut over to this
Vercel project 2026-05-31 (propagating ≤24h); also on
chess-leader.vercel.app (secondary). Canonical/OG/sitemap → chess-spb.com.

## Stack

- Vite 7 + React 19 + TypeScript.
- react-router-dom v7 — `BrowserRouter` in `src/main.tsx`,
  `StaticRouter` in `src/entry-server.tsx`. `vite.config.ts` dedupes
  React (`react`, `react-dom`, `react-router-dom`).
- V4 design system in `src/styles/v4.css` scoped under `.v4v` —
  hand-written CSS (Tailwind/PostCSS removed).
- `libphonenumber-js` — RU phone validation + as-you-type mask
  (`src/lib/phone.ts`). Analytics/UTM wrappers in `src/lib/`.
- Build-time SSG: `npm run build` = `tsc --noEmit && vite build &&
  vite build --ssr src/entry-server.tsx --outDir dist-ssr && node
  scripts/prerender.mjs`. The prerender script renders each route
  with `renderToString` and writes `dist/<route>/index.html` with
  per-page meta + JSON-LD, plus `dist/sitemap.xml`.

## Pages

| Path | Component | Notes |
|------|-----------|-------|
| `/` | `Home` | hero + storyboard + stats + benefits + coaches + reviews + where |
| `/prices` | `Prices` | 3 tiers + compare + promo + included + FAQ |
| `/schedule` | `Schedule` | mode tabs + 7-day week + coaches note |

Pattern mirrors `maksi/`. `MenuOverlay` lists only these three —
`/tournaments`, Контакты, Блог intentionally absent (per user
instruction). `*` falls back to Home.

## SEO

- Per-page `<title>` / `<meta name="description">` / canonical / `og:*`
  / `twitter:*` written by `scripts/prerender.mjs` from `ROUTES`.
- JSON-LD: `EducationalOrganization` + `WebSite` on `/`; `Service`
  (3 `Offer`) + `FAQPage` on `/prices`; `Course` (2 `CourseInstance`)
  on `/schedule`.
- `public/robots.txt` (allows all, points at sitemap).
- `dist/sitemap.xml` auto-generated by the prerender script from
  indexable routes.
- Yandex.Metrika id `88489627` (from legacy chess-spb.com) inline
  in `index.html` with `ssr:true, webvisor:true, clickmap:true`,
  plus `<noscript>` pixel.

## Routing + chrome

`src/App.tsx` reads `useLocation()` for current page, hosts
`MenuOverlay`, and provides `navigate()` to children. The
`<Routes>` block has explicit `Route` entries for `/`, `/prices`,
`/schedule`, plus a `*` fallback to Home.

Logo across header + footer + menu is the actual chess-spb.com
brand mark — inline SVG in `src/components/icons/LogoMark.tsx`,
paths use `currentColor` so the header renders it in teal-deep and
the dark footer in white.

## Responsive

Single `src/styles/v4.css`:
- Default: mobile.
- `@media (min-width: 768px)` — tablet: 3-col grids
  (storyboard / stats / benefits / coaches / tiers), 2-col schedule
  week, 2-col Where (map + form), sticky CTA hidden, full phone in
  nav.
- `@media (min-width: 1024px)` — desktop: max-width 1100 container,
  inline nav links + header CTA, board-frame hero (8x4 chessboard
  cells + knight badge), 4-col stats / benefits, 3-col coaches,
  3-col schedule week, 4-col footer.

Verified visually at 375 (mobile), 820 (tablet portrait), 1280
(desktop) via `preview_*` tools; layouts confirmed via
`getComputedStyle` on representative grids.
